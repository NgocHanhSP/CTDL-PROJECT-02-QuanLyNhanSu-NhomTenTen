## Quy uoc dat ten

- Class: PascalCase. Ham/method: camelCase. Hang so va gia tri enum: UPPER_CASE.
- Bien: tien to Hungarian (`str`, `i`, `ui`, `b`, `c`, `e`, `p`, `vec`), bien member them tien to `_`.
